# Text to vector Braille (SVG)

Web-tool for converting text to vector Braille (SVG format) for designers and accessibility projects.

## Features

- **Ukrainian, Russian, English** alphabets support
- **Numbers** with automatic Braille number prefix
- **Capital letters** with Braille capital prefix
- **Punctuation marks** support
- **Customizable parameters**: dot size, letter spacing, line spacing
- **Labels toggle**: show/hide original characters under Braille symbols
- **SVG export**: download as `.svg` file or copy SVG code to clipboard
- **Live preview**: real-time conversion as you type

## Usage

1. Open `braille_converter.html` in any modern browser
2. Type or paste text into the input field
3. Adjust visual parameters (dot size, spacing) as needed
4. Download SVG or copy to clipboard

## Braille Standard

The converter uses the 6-dot Braille cell layout:

```
1 4
2 5
3 6
```

Based on Ukrainian Braille standard with extensions for Russian and English alphabets.
